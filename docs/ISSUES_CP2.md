# CP2 issues (create these on GitHub in this order)

Issues and pull requests share one number sequence. CP1 used #1 to #11, so these come out as **#12 to #17** if created before any CP2 pull request.
`scripts/create_issues_cp2.sh` does this automatically if the GitHub CLI is installed.

| # | Title | Owner | Body |
|---|---|---|---|
| 12 | GIF writer, bitmap text and animated minimap tour | Nelly Nkatha | Palette quantiser, LZW compression and GIF file writer; a 5x7 bitmap font for labelling figures; an animated minimap that follows a steering player and shows the lit field of view. |
| 13 | Matrix transformations | Darrel Kariuki | 3x3 homogeneous matrices for translate, rotate, scale, shear and reflect, composition, inverse, and a demo showing every operator and the effect of order. |
| 14 | Animation: easing, keyframes and path following | Ravine Riang'a | Easing curves including a Bezier ease, keyframe tracks, shortest-arc angle blending, an arc-length path sampler, the camera route, and a demo with an easing race. |
| 15 | Torch sprites | Shawn Owiro | Projection of torches into camera space with a rotation matrix, size and fog by distance, per-column hiding behind walls, and a demo with approach and sidestep animations. |
| 16 | First-person renderer and walkthrough | Arthur Asava | Brick walls, fog, torch light with shadow rays, head bob, sprites, a walkthrough animation along the camera route, and a hall demo with approach and sidestep animations. |
| 17 | CP2 tests, documentation and evidence | Anita Bichanga | Tests for every CP2 module, README and technique documentation, the proposed-vs-actual write-up, and the CP2 evidence PDF. |
